# World Top 300 Books｜世界精选 TOP 300 图书馆

一个面向长期阅读、双语学习与知识体系建设的个人数字图书馆。精选 300 本具有持久影响力的世界图书，覆盖文学、历史、哲学、政治、心理、科学、经济、人物传记、计算机科技与教育成长。

> **重要说明：** 世界上不存在一个被所有国家、学者和读者共同认可的“全球史上最佳 300 本书”官方榜单。本项目是依据公开书单、历史影响、跨文化代表性与学习价值制作的编辑精选，不把主观选择伪装成客观的世界统一排名。

## 项目目标

- 建立覆盖 10 个领域的 300 本精选书目。
- 每本书提供约 **300 字中文内容概述 + 300 词英文内容概述**。
- 标注作者、首次出版/成书年份、所属领域与入选依据。
- 总结每本书的核心学习价值、关键主题与推荐读者。
- 为英语学习者提供自然、准确、可理解的英文阅读材料。
- 持续核对书名、作者、版本与出版时间；存在争议的古籍会标明约数或版本差异。

## 每本书的统一格式

1. 书名（原文名与常见中文译名）
2. 作者
3. 首次出版/成书年份（必要时注明连载、分卷或年代争议）
4. 所属分类与入选依据
5. 中文内容概述（目标约 300 字）
6. English summary（目标约 300 words）
7. 核心学习价值（3–6 点）
8. 关键主题与推荐读者
9. 参考来源（用于核对书目信息与榜单入选依据）

## 排名与选书方法

本项目采用编辑性综合评价，而非声称存在唯一正确的全球名次。评价维度与权重见 [RANKING-METHODOLOGY.md](RANKING-METHODOLOGY.md)。目录编号是馆藏编号，不等同于绝对世界排名。分类内部会参考权威书单的排序、跨时代影响与文化代表性安排阅读优先级。
